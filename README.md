# OP Tree Drops

Mod Forge 1.20.1 para Minecraft Java.

Quando o jogador quebra qualquer tronco de árvore em survival, o bloco solta vários itens OP aleatórios, como netherite, diamante, elytra, beacon, totem, maçã encantada e equipamentos com encantamentos acima do normal.

## Como gerar o .jar

Instale Java 17 e Gradle.

```bash
gradle build
```

O arquivo final vai aparecer em:

```txt
build/libs/op-tree-drops-1.0.0.jar
```

Coloque esse `.jar` na pasta `mods` do Minecraft Forge 1.20.1.

## GitHub Actions

Se não quiser buildar no celular ou PC, envie esse projeto para um repositório GitHub e rode a action `Build Mod`. O `.jar` vai sair nos artifacts.
